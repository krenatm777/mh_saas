# MusharaqaHub — клиентский путь: что подключить

Добавлены страницы клиентского пути, чтобы закрыть замечание PayLink
(личный кабинет, оплата, демонстрация, рабочая форма, описание флоу).

## Новые страницы
| Файл | Назначение |
|---|---|
| `cabinet.html` | Демо-личный кабинет с тестовым входом (дашборд: объект ИС, модули, документы, оплата) |
| `payment.html` | Страница оплаты (checkout): сумма, детали, кнопка «Оплатить картой» |
| `success.html` / `fail.html` | Страницы результата оплаты (возврат с PayLink) |
| `thanks.html` | Подтверждение отправки заявки |
| `payment-flow.html` | Описание платёжного флоу (можно показать PayLink) |

## 1. Подключить форму заявки (Formspree) — обязательно
Сейчас форма отправляет на Formspree по плейсхолдеру. Чтобы заработала:
1. Зарегистрируйтесь на **formspree.io** (бесплатно), создайте новую форму, укажите e-mail получателя (info@musharaqahub.com).
2. Скопируйте ID формы (вид `xxxxxable`), он в адресе `https://formspree.io/f/XXXXXXX`.
3. В файле `order.html` замените `YOUR_FORMSPREE_ID` на ваш ID (атрибут `action` формы).
4. Отправьте тестовую заявку, подтвердите адрес по письму Formspree. После отправки клиент попадает на `thanks.html`.

> ⚠️ Formspree хранит заявки на своих серверах (США). Для **боевого** хранения ПДн (ст. 12 Закона РК № 94-V — хранение в РК) замените на казахстанский бэкенд/CRM: в `order.html` поставьте в `action` ваш endpoint в РК. Для ревью PayLink Formspree допустим.

## 2. Подключить оплату PayLink — когда дадут ссылку/ключи
В `payment.html` найдите строку:
```js
var PAYLINK_URL="";
```
Вставьте в кавычки ссылку на платёжную страницу PayLink (или подключите их виджет по их документации). После этого кнопка «Оплатить картой» будет вести на реальную оплату, а PayLink после платежа вернёт клиента на `success.html` / `fail.html` (эти адреса укажите в настройках мерчанта PayLink как return URL).

## 3. Описание платёжного флоу для PayLink
Готово на странице `payment-flow.html` (и EN, и RU). Можно дать ссылку или переслать текст.

## Важно (честно)
- Кабинет — **демо** (вход проверяется на стороне браузера, это не боевая авторизация). Для продакшена нужна реальная авторизация на бэкенде.
- Пока платформа в разработке, кабинет показывает демо-данные. Если PayLink потребует полноценный рабочий сервис — демо закроет ревью, но продукт нужно довести.
- Оплата — только после подключения PayLink (поддельной оплаты в коде нет).
